# โต๊ะโป๊กเกอร์อนันต

โป๊กเกอร์ No-Limit Texas Hold'em เล่นออนไลน์ 2–9 คน ด้วยชิปในเกมเท่านั้น คนเปิดโต๊ะตั้งบลายด์ ชิปเริ่มต้น และชิปของผู้เล่นแต่ละคนได้เอง

ลิงก์เล่น: https://ananta-cards.github.io/Anantacard-poker/ (GitHub Pages จากสาขา main) · ไม่ต้องมีบัญชีอะไร เปิดลิงก์แล้วเล่นได้เลย

## เล่นยังไง

1. เปิดลิงก์ ใส่ชื่อ แล้วกด **เปิดโต๊ะ** (ตั้งชื่อโต๊ะ บลายด์ ชิปเริ่มต้น ที่นั่งสูงสุด)
2. กด **คัดลอกลิงก์เชิญ** (ลิงก์ลงท้าย `#รหัสโต๊ะ`) ส่งให้เพื่อน เพื่อนเปิดแล้วใส่ชื่อก็เข้าโต๊ะได้ หรือกรอกรหัส 5 ตัว หรือกดจากรายการ "โต๊ะที่เปิดอยู่"
3. แผงเจ้ามือ: ตั้งชิปของแต่ละคน เติมชิป ให้คนนั่ง/ลุก บังคับหมอบ และแก้บลายด์ได้ระหว่างมือ
4. กด **แจกมือใหม่** มือถัดไปเริ่มเองหลังจบมือ 6 วินาที (ปิดได้)

## ทำงานยังไง

- เว็บเป็นไฟล์เดียว (`index.html`) ไม่มีเซิร์ฟเวอร์ของเราเอง ส่งข้อมูลกันผ่านเซิร์ฟเวอร์ MQTT สาธารณะฟรี `wss://broker.emqx.io:8084/mqtt` (`net.js`): แต่ละคนเก็บ "presence" ของตัวเองเป็นข้อความ retained ที่ `anantapoker/v1/t/<รหัสโต๊ะ>/<peer>` ส่งซ้ำทุก 15 วินาที เงียบเกิน 50 วินาทีถือว่าออกไปแล้ว
- เครื่องของคนเปิดโต๊ะเป็นเจ้ามือ: สับไพ่ รับคำสั่ง และส่งสถานะโต๊ะให้ทุกคน คนอื่นส่งคำสั่ง (หมอบ คอล เรส) ผ่าน presence ของตัวเอง
- ใครรู้รหัสโต๊ะก็เข้าดูหรือส่งข้อมูลปลอมได้ เพราะเซิร์ฟเวอร์เป็นของสาธารณะ ใช้กับเพื่อนและชิปในเกมเท่านั้น
- ไพ่ในมือเข้ารหัสด้วย ECDH P-256 + AES-GCM ด้วยกุญแจของผู้เล่นแต่ละคน คนอื่นบนโต๊ะอ่านไม่ได้ (เครื่องเจ้ามือรู้ไพ่ทุกใบ เพราะเป็นคนแจก)
- เจ้ามือเก็บสถานะโต๊ะไว้ใน localStorage ถ้าปิดหน้าแล้วเปิดใหม่ กด "กลับไปคุมโต๊ะ" ได้ ระหว่างที่เจ้ามือไม่อยู่เกมจะหยุด
- ผู้เล่นที่ออกจากโต๊ะตอนถึงตาตัวเองจะหมอบอัตโนมัติหลัง 20 วินาที

## ไฟล์

```
index.html     หน้าเว็บที่ใช้จริง สร้างด้วย node build.js (อย่าแก้ตรง)
net.js         ห้องเรียลไทม์ผ่าน MQTT
engine.js      เอนจินเกม: สำรับ ตัดสินมือ เดิมพัน No-Limit ไซด์พอต (ฟังก์ชันล้วน ใช้ได้ทั้ง node และเบราว์เซอร์)
page.html      หน้าเกม มีช่อง /*ENGINE*/
build.js       npm install แล้ว node build.js -> index.html
test/engine.js node test/engine.js [จำนวนเกมสุ่ม]  ทดสอบตัดสินมือ ไซด์พอต เรสไม่ครบ ชิปไม่หาย
test/ui.js     node test/ui.js  เปิดเบราว์เซอร์หลายคนเล่นจริงผ่านเซิร์ฟเวอร์ MQTT จำลองในเครื่อง (ต้องมี playwright)
```
