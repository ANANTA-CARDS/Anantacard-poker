# โต๊ะโป๊กเกอร์อนันต

โป๊กเกอร์ No-Limit Texas Hold'em เล่นออนไลน์ 2–9 คน ด้วยชิปในเกมเท่านั้น คนเปิดโต๊ะตั้งบลายด์ ชิปเริ่มต้น และชิปของผู้เล่นแต่ละคนได้เอง

ลิงก์เล่น: https://claude.ai/artifact/HMSLf9xp53fCwJqgLHTsRq

## เล่นยังไง

1. เปิดลิงก์ ใส่ชื่อ แล้วกด **เปิดโต๊ะ** (ตั้งชื่อโต๊ะ บลายด์ ชิปเริ่มต้น ที่นั่งสูงสุด)
2. ส่งรหัสโต๊ะ 5 ตัวให้เพื่อน เพื่อนเปิดลิงก์เดียวกันแล้วกรอกรหัส หรือกดจากรายการ "โต๊ะที่เปิดอยู่"
3. แผงเจ้ามือ: ตั้งชิปของแต่ละคน เติมชิป ให้คนนั่ง/ลุก บังคับหมอบ และแก้บลายด์ได้ระหว่างมือ
4. กด **แจกมือใหม่** มือถัดไปเริ่มเองหลังจบมือ 6 วินาที (ปิดได้)

เพื่อนต้องได้รับเชิญผ่านเมนู Share ของหน้า (เชิญด้วยอีเมล) และลงชื่อเข้า claude.ai ก่อน คนที่เปิดผ่านลิงก์สาธารณะเข้าโต๊ะไม่ได้

## ทำงานยังไง

- ไม่มีเซิร์ฟเวอร์ เครื่องของคนเปิดโต๊ะเป็นเจ้ามือ: สับไพ่ รับคำสั่ง และส่งสถานะโต๊ะให้ทุกคนผ่านความสามารถ `room` ของหน้า Artifact (presence ต่อคน ไม่เกิน 4 KiB)
- ไพ่ในมือเข้ารหัสด้วย ECDH P-256 + AES-GCM ด้วยกุญแจของผู้เล่นแต่ละคน คนอื่นบนโต๊ะอ่านไม่ได้ (เครื่องเจ้ามือรู้ไพ่ทุกใบ เพราะเป็นคนแจก)
- เจ้ามือเก็บสถานะโต๊ะไว้ใน localStorage ถ้าปิดหน้าแล้วเปิดใหม่ กด "กลับไปคุมโต๊ะ" ได้ ระหว่างที่เจ้ามือไม่อยู่เกมจะหยุด
- ผู้เล่นที่ออกจากโต๊ะตอนถึงตาตัวเองจะหมอบอัตโนมัติหลัง 20 วินาที

## ไฟล์

```
engine.js      เอนจินเกม: สำรับ ตัดสินมือ เดิมพัน No-Limit ไซด์พอต (ฟังก์ชันล้วน ใช้ได้ทั้ง node และเบราว์เซอร์)
page.html      หน้าเกม มีช่อง /*ENGINE*/
build.js       node build.js -> dist/poker.html
test/engine.js node test/engine.js [จำนวนเกมสุ่ม]  ทดสอบตัดสินมือ ไซด์พอต เรสไม่ครบ ชิปไม่หาย
test/ui.js     node test/ui.js  เปิดเบราว์เซอร์หลายคนเล่นจริงผ่าน room จำลอง (ต้องมี playwright)
```
